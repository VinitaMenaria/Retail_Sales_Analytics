# Retail Sales & Profit Analytics Project

## Project Overview
This project performs end-to-end sales and profit analysis for a retail business using Python.
The goal is to transform raw sales data into meaningful business insights.

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains:
- Date
- Region
- Product
- Category
- Quantity
- Price
- Cost

## Analysis Performed
- Data loading and inspection
- Data cleaning and date processing
- Feature engineering (Revenue, Profit, Month)
- Monthly sales trend analysis
- Product-wise and region-wise revenue analysis
- Profit contribution analysis
- Dashboard-style visualization using Matplotlib

## Key Business Insights
- Identified top-performing products by revenue and profit
- Analyzed monthly sales trends
- Compared regional sales performance
- Highlighted profit contribution by product

## Outcome
This project demonstrates real-world data analyst skills such as data cleaning, analysis,
visualization, and business insight generation.
